대한민국의 인기 차트

전곡 듣기 설정

기본 재생은 30초 미리듣기입니다. 곡 전체는 YouTube로 재생하며, 곡을 검색하려면 본인의 YouTube Data API 키가 한 번 필요합니다. 무료이며 카드 등록은 필요 없습니다.

API 키 만드는 방법
  1. Google Cloud 콘솔에서 Google 계정으로 로그인하고 프로젝트를 만듭니다.
  2. YouTube Data API v3 페이지에서 사용을 누릅니다.
  3. 사용자 인증 정보에서 사용자 인증 정보 만들기 → API 키를 선택합니다.
  4. 만든 키를 열어 애플리케이션 제한사항은 웹사이트(HTTP 리퍼러)로 두고 이 앱 주소(예: https://내아이디.github.io/*)를 추가합니다. API 제한사항은 YouTube Data API v3만 선택하고 저장합니다.
  5. 키를 복사해 아래에 붙여넣습니다.

검색 1회는 할당량 100을 쓰며 하루 기본 10,000이므로 하루 약 100곡을 검색할 수 있습니다. 한 번 찾은 곡은 이 기기에 7일간 저장되어 다시 검색하지 않습니다.

키는 이 기기의 브라우저에만 저장되고 개발자나 다른 서버로 전송되지 않습니다. 위 4번의 제한을 꼭 설정해 주세요.

Orbitone은 YouTube API 서비스를 사용합니다. 전곡 듣기를 사용하면 YouTube 서비스 약관과 Google 개인정보처리방침에 동의하는 것으로 간주됩니다.

Apple Music 국가별 인기 차트를 우선 사용합니다. 정적 호스팅에서는 iTunes 판매 차트로 대체될 수 있으며 출처를 표시합니다.

재생과 개인정보

YouTube·Spotify는 재생/연결 시 해당 서비스에 접속합니다. 자동재생, 지역, 로그인 및 구독 제한이 적용될 수 있습니다. 음악을 다운로드하거나 오프라인 저장하지 않습니다.

플레이리스트와 연결한 영상 ID는 이 기기에 저장됩니다. 차트 로딩 실패 시 캐시 또는 명확히 표시된 예시를 보여줍니다.

이 곡의 플레이어 연결

공식 아티스트 채널인지 확인한 링크를 넣어주세요. YouTube 재생 불가 시 연결된 Spotify 곡을 대안으로 표시합니다.

음악 여행 보내기

플레이리스트를 링크 목록으로 공유하거나 파일로 보관하세요.

YouTube Music / Spotify로 보내기

계정에 자동 생성하려면 각 서비스의 OAuth 동의와 개발자 앱 등록이 필요합니다. 이 버전에서는 자동 전송하지 않습니다.

YouTube API의 플레이리스트가 YouTube Music에도 표시되는지는 보장되지 않습니다.

Orbitone을 홈 화면에

iPhone / iPad: Safari에서 공유 → 홈 화면에 추가를 선택하세요.

Android / 데스크톱: 브라우저 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택하세요.

설치된 앱에서 실행하면 설치 아이콘이 사라집니다. HTTPS 또는 localhost가 필요합니다.
